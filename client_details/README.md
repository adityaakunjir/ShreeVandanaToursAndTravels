# Client Details Folder

This folder is the central place to drop any information, assets, and requirements for the client (e.g., Shree Vandana Tours and Travels). 

## How to use this folder:
1. **Logos & Images**: Drop the client's logo (e.g., `logo.png` or `logo.svg`) and any brand images here.
2. **Client Info**: Update the `client_info.json` file with the client's specific details like their phone number, email address, physical address, and social media links.
3. **Documents**: You can drop PDF requirements, Word documents, or text files with the client's specific tour packages and pricing here.

Once you add files to this folder, simply tell me (Antigravity), and I will read these files to automatically update the website's Navigation, Footer, Contact sections, and Color Schemes to match the client's brand!
